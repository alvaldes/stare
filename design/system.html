Stare design system

Synced verbatim from landing/src/style.css (the web marketing site). Companion doc: design/system.md.

Scope: these tokens describe the web landing page, not the native window. Stare is a native macOS menu-bar app. Its real windows must use macOS semantic colors (NSColor.windowBackgroundColor, .controlBackgroundColor, .separatorColor), the system font, and SF Symbols — not these web tokens. Only where a token coincides with an Apple system color (--color-ink-blue = systemBlue, --color-ink-green = systemGreen, --color-ink-orange = systemOrange, --color-graphite ≈ label, --color-desk ≈ window background, --color-rule ≈ separator) may the value stand in for its macOS equivalent. Nothing marked “landing only” leaks into the native window.

Accessibility rules carried from source

Focus is always visible: :focus-visible{outline:2px solid var(--color-ink-blue);outline-offset:2px}. Reduced motion is honored: the source forces all animation to finish in 1ms under prefers-reduced-motion (line 719) — artboards follow the same pattern. Button fills use a deepened blue (#0062cc, ≈ ink-blue darkened) so white labels pass WCAG AA at small sizes; raw #007aff stays for accents, focus rings, and ≥ 18px text.
